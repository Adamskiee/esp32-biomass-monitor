# Biomass IoT Project

## Dependencies

This project relies on several third-party libraries. Install the required libraries using the **Arduino Library Manager** (Sketch > Include Library > Manage Libraries...).

### Required Libraries
- **Adafruit PM25 AQI Sensor** by Adafruit (v2.0.0)
- **DHT sensor library** by Adafruit (v1.4.7)
